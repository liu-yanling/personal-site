背景

            
房建甲方成本管理长期存在两大痛点：一是建材询价靠电话、微信逐家问供应商，人工整理报价、横向比价、手写分析报告，周期长、口径不一，价格随行情波动时常错过最佳采购时点；二是成本动态监控依赖 Excel 台账和月度报表，超支发现滞后一两个月，签证变更零散难追溯，甲方常在结算阶段才发现项目超概。市面通用费控工具不懂房建成本科目体系，也没把多源报价数据做成可追溯的知识库。

          

          

            
目标

            
从 0 到 1 打造 AI 驱动的房建成本工作台 BuildQuote —— 以多 Agent 编排 + RAG 知识库，把建材询价比价、成本动态归集、超支预警串成一条可对话的产品链路，让造价岗和成本经理从翻 Excel 台账变成自然语言追问。

          

        


        

          

            
Agent 架构

            Lead 主控 + 3 Subagent + RAG / 规则引擎 / 评测看板
          

          

            

              

                Lead 主控
                任务拆解 · 上下文隔离 · 结果仲裁 · 收口输出
              

            

            

            

              

                归集 Agent
                合同 · 进度款 · 签证 → 按科目归集实际成本
              

              

                预警 Agent
                预算 vs 实际 · 黄警 ≥5% / 红警 ≥10% · 附依据解释
              

              

                问答 Agent
                自然语言追问费用构成 · RAG 带引用作答
              

            

            

            

              

                RAG 知识库
                合同清单 · 签证单 · 结算资料 · 多源报价 → 切分 / 混合召回 / 引用治理
              

              

                规则引擎 + 评测看板
                数字一律走规则、不经模型；召回率 / 引用可追溯率 / 预警覆盖率
              

            

            

              主控与调度
              Subagent
              知识与规则底座
